What is Grub?

GRUB (Grand Unified Bootloader) is the essential software that starts your computer by loading the operating system (like Linux, Windows) when you turn it on, acting as a menu to choose between different OSes or kernel versions, and is the standard boot manager for most Linux distributions

  • Runs right after BIOS or UEFI
  • Loads the Linux kernel into memory
  • Can boot Linux, Windows, and other systems
  • Provides a command line for manual recovery

Grub commands

ls

Lists available disks and partitions that GRUB can detect.

set root=(hdX,gptY)

Sets the partition that contains the Linux kernel and boot files.

linux /vmlinuz

Loads the Linux kernel into memory with optional boot parameters.

boot

Starts the boot process using the loaded kernel and initrd.
